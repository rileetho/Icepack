# Icepack
This is the GitHub repository for all codes, information I use to learn and run [icepack](https://github.com/icepack). I downloaded icepack using [this code](https://git.strempfer.dev/sebastian/firedrake-conda) which downloads Firedrake, the package icepack is built on, and icepack itself, using [conda](https://github.com/conda-forge/miniforge) via miniforge.  

**Important packages:**  
*Conda*: A package manager and environmental management system.  
*Firedrake*: A system for the solution of partial differential equations using the finite element method (FEM).  
*icepack*: A Python library for solving the equations of motion of glacier flow.
